# Nurse's Log downloads

Installers for **Nurse's Log**, a Windows app for the school nurse's office: student health info, medications and doses, office visits, and an audit log.

## Install

1. Open the [latest release](https://github.com/c3dprints/nurse-log-releases/releases/latest).
2. Download **NursesLog-Setup-X.Y.Z.exe** and run it. No admin rights, Git or Node.js needed.
3. If Windows says "Windows protected your PC" (the installer is not code-signed yet), click **More info**, then **Run anyway**.

Installed copies update themselves from Settings > Updates. Student records stay on the PC in `%APPDATA%\NurseLog`; updates and uninstalling never touch them.

## Beta software

This is a beta (pre-release) version for evaluation and testing only. It has not been independently tested, audited or certified and is not licensed for production use. Further testing and proper licensing are required before it is used to keep real student health records.
